# Concrete Compressive Strength data

`Concrete_Data.xls` and `Concrete_Readme.txt` are copied unchanged from the original project. Preserve the original observation order.

Source: [UCI Concrete Compressive Strength](https://archive.ics.uci.edu/ml/datasets/Concrete+Compressive+Strength).

There are 1,030 observations, eight predictors, and compressive strength as the response. Observations 501–630 (excluding the Excel header) form the 130-row test set; the remaining 900 form the training set.

The supplied `Concrete_Readme.txt` contains the original attribution and reuse notice. Retain it with the dataset.
